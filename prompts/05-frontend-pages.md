Crie frontend estático em HTML/CSS/JavaScript puro para GitHub Pages.

Consuma somente os JSON públicos do backend; o navegador nunca chama SerpApi ou Telegram. Use caminhos relativos compatíveis com /nome-do-repositorio/.

Mostre viagem, passageiros, rotas, melhor preço confirmado, menor histórico comparável, ofertas por rota, companhia, escalas, duração, histórico visual simples, filtros, links, última consulta e estados de dados antigos/falhas/incompletos.

Deixe claro se o histórico é menor preço diário ou oferta específica. Não use preços fictícios na publicação. Garanta responsividade, pt-BR, moeda BRL, acessibilidade, contraste, inserção segura no DOM e ausência de credenciais/analytics. O painel é somente leitura.

Valide celular/desktop e documente execução local.
